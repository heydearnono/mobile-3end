## M1-3 排好序的列表 · `ui/Screens.kt`

<details><summary>提示 2</summary>

`remember` 可以带参数：`remember(a, b) { ... }`，任一参数变化时重新计算 lambda，否则复用上次的结果。和 Vue 的 `computed` 一样，参数就是它的依赖。
</details>

<details><summary>答案</summary>

```kotlin
val sorted: List<FileItem> = remember(files, order) { sortFiles(files, order) }
```
</details>

想一想：
- 直接写 `val sorted = sortFiles(files, order)`，不加 `remember`，测试也能过。那 `remember` 带来了什么？什么时候值得加？
- 加了 `remember` 但不带参数（`remember { sortFiles(files, order) }`），会出什么 bug？
